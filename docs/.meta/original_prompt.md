# 原始用户 Prompt（SSOT，禁止改写）

> 归档时间：2026-08-21 19:57 (GMT+8)
> 归档人：PM Agent (Alkaid-SOP v13.0)
> 用途：Phase 5 Auditor Agent 的评审输入基准

---

使用Go语言实现一个全栈自动化敏捷项目管理与看板系统 (类似Mini Jira / Trello)

业务背景：适合软件开发团队的敏捷开发管理工具，包含看板、Sprint（迭代）、Bug 追踪和甘特图。

前端页面（Vue 3 + Pinia）：看板视图 (Kanban Board)：支持任务卡片在"待处理"、"开发中"、"已测试"、"已完成"列之间拖拽同步。甘特图/时间线：直观展示项目各任务的开始/截止时间及依赖关系。统计分析页：燃尽图（Burn-down Chart）、团队生产力折线图。

Go 后端核心实现：状态机引擎：任务状态转换（如：只有测试人员能将 Bug 改为"已解决"）采用状态机模式硬编码或配置化。自动化触发器：类似"当任务进入已完成列时，自动发送邮件通知产品经理"的 Hook 机制。复杂的统计聚合：编写高效的 SQL/聚合查询，实时计算迭代进度和燃尽图数据。

文件数与代码量：约 30 个 Go 文件，代码量约 5000 - 7500 行。
